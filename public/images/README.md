# VektorStore Image Assets

This directory contains all image assets used by the VektorStore website. Please place the following images in their respective locations:

## Root Level Images
- `logo.png` - Main VektorStore logo (used in header)
- `banner1.png` - Hero banner slide 1 (home page)
- `banner2.png` - Hero banner slide 2 (home page)
- `banner3.png` - Hero banner slide 3 (home page)

## Image Specifications
- Logo: PNG format, transparent background recommended
- Banners: PNG format, recommended dimensions 1920x600px
- Product images: JPG format, recommended dimensions 800x1000px for main images, 400x500px for additional images
- All images should be optimized for web (compressed appropriately)
